# 组盘取消功能优化说明

## 功能概述

优化了`/#/boxDisk`路由下的组盘取消按钮功能，现在点击后会弹出一个子页面，提供更精细的操作控制。

## 新增功能

### 1. 组盘取消弹窗
- **触发方式**: 点击"组盘取消"按钮
- **显示内容**: 该容器编码下的所有已组盘信息
- **操作选项**: 提供两个操作按钮

### 2. 数据表格
- **多选功能**: 每行数据都有复选框，支持多选
- **显示字段**: 
  - 收料条形码
  - 物料编码
  - 物料名称
  - 入库数量
  - 操作（查看详情）

### 3. 操作按钮

#### 组盘取消按钮
- **功能**: 与原来的功能完全一致
- **调用接口**: `POST /wms/stock/stocksDisBindBox?boxCode=XXX`
- **操作范围**: 取消整个容器的组盘
- **状态**: 当容器中没有数据时禁用

#### 数据清除按钮
- **功能**: 清除选中的特定条码数据
- **调用接口**: `POST /wms/stock/pdaDataClear`
- **请求参数**:
  ```json
  {
    "boxCode": "容器编码",
    "barcodes": ["条码1", "条码2", "条码3"]
  }
  ```
- **操作范围**: 仅清除选中的数据
- **状态**: 当没有选中任何数据时禁用

## 技术实现

### 1. 新增文件
- `BoxDiskCancelModal.vue`: 组盘取消弹窗组件
- `IncellByPeople.ts`: 添加了`pdaDataClear`接口调用函数

### 2. 修改文件
- `BoxDisk.vue`: 修改组盘取消按钮逻辑，集成弹窗组件

### 3. 组件特性
- **响应式设计**: 适配移动端和桌面端
- **加载状态**: 按钮操作时显示加载状态
- **错误处理**: 完善的错误提示机制
- **数据验证**: 操作前进行必要的数据验证

## 使用流程

### 组盘取消操作
1. 扫描容器编码
2. 点击"组盘取消"按钮
3. 在弹窗中点击"组盘取消"按钮
4. 确认操作，系统执行组盘取消

### 数据清除操作
1. 扫描容器编码
2. 点击"组盘取消"按钮
3. 在弹窗中勾选要清除的数据行
4. 点击"数据清除"按钮
5. 确认操作，系统执行数据清除

### 状态说明
- **组盘取消按钮**: 当容器有数据时可用，无数据时禁用
- **数据清除按钮**: 当选中数据时可用，未选中时禁用
- **加载状态**: 操作进行中时按钮显示加载动画

## 错误处理

### 常见错误情况
1. **容器编码为空**: 提示"没有容器信息"
2. **未选中数据**: 提示"请选择要清除的数据"
3. **网络错误**: 显示具体的错误信息
4. **接口异常**: 显示"接口推送异常"提示

### 成功反馈
- **组盘取消成功**: 显示成功消息并刷新页面数据
- **数据清除成功**: 显示成功消息并关闭弹窗

## 兼容性说明

- 保持了原有的组盘取消功能不变
- 新增的数据清除功能不影响现有业务流程
- 弹窗设计适配移动端操作习惯
- 支持键盘和触摸操作

## 注意事项

1. **数据安全**: 数据清除操作不可逆，请谨慎操作
2. **权限控制**: 确保用户有相应的操作权限
3. **数据同步**: 操作完成后会自动刷新页面数据
4. **性能考虑**: 大量数据时建议分批操作
